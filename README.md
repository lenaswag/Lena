# 📘 Past or Present Perfect?

고등학교 1학년 학습자를 위한 **Simple Past(단순 과거형)**과 **Present Perfect(현재완료형)** 구분 연습 웹앱입니다.

학생들이 문장 속 **시간 표현과 문맥 단서**를 확인하면서 두 시제의 차이를 자연스럽게 익힐 수 있도록 구성했습니다.

---

## 🎯 Learning Goal

이 활동의 목표는 학생들이 다음 두 시제의 사용 차이를 이해하고 구분하는 것입니다.

- **Simple Past**
  - 과거의 특정 시점에 시작되고 끝난 행동
  - 예: `yesterday`, `last year`, `two days ago`

- **Present Perfect**
  - 과거의 경험이나 행동이 현재와 연결되어 있는 경우
  - 형태: `have/has + past participle`
  - 예: `ever`, `never`, `already`, `yet`, `since`, `for`

---

## 👩‍🎓 Target Learners

- **Grade 10**
- 한국 고등학교 1학년 수준의 영어 학습자
- 단순 과거형과 현재완료형을 배웠지만, 실제 문장에서 두 시제를 구분하는 데 어려움을 느끼는 학생

---

## 🧩 Activity Flow

학생은 각 문장을 읽고 주어진 동사를 알맞은 형태로 바꾸어 빈칸에 입력합니다.

1. 영어 문장을 읽습니다.
2. 문장 속 시간 표현과 의미를 확인합니다.
3. 주어진 동사를 **Simple Past** 또는 **Present Perfect** 형태로 입력합니다.
4. 정답을 확인합니다.
5. 첫 번째 시도에서 틀린 경우, 바로 정답을 제공하지 않고 **힌트**를 제공합니다.
6. 학생은 힌트를 확인한 뒤 한 번 더 도전합니다.
7. 두 번째 시도 후에는 정답과 간단한 문법 설명을 확인할 수 있습니다.
8. 모든 문제를 완료하면 최종 점수와 핵심 문법 내용을 다시 확인합니다.

---

## ✨ Key Features

- 📝 **직접 입력형 활동**
  - 학생이 답을 선택하는 대신 직접 동사의 형태를 입력합니다.

- 💡 **Hint-based Feedback**
  - 첫 오답에서는 정답 대신 시간 표현이나 문맥 단서에 대한 힌트를 제공합니다.

- 🔁 **Second Chance**
  - 힌트를 확인한 뒤 한 번 더 답할 수 있습니다.

- ✅ **Immediate Feedback**
  - 정답 여부와 함께 해당 시제를 사용하는 이유를 바로 확인할 수 있습니다.

- 📊 **Progress & Score**
  - 현재 문제 번호와 점수를 실시간으로 확인할 수 있습니다.

- 📚 **Final Review**
  - 활동이 끝난 후 Simple Past와 Present Perfect의 핵심 차이를 다시 복습할 수 있습니다.

## 💬 Feedback Logic

이 활동은 학생이 틀렸을 때 바로 답을 보여주는 대신, **스스로 다시 생각할 기회**를 제공하도록 설계했습니다.

```text
정답 입력
   ↓
정답인가?
   ↓
Yes → 정답 + 문법 설명
   ↓
No
   ↓
첫 번째 시도 → 힌트 제공 → 다시 도전
   ↓
두 번째 시도 → 정답 + 문법 설명
```

## 📌 Example

**Sentence**

> I _____ Jeju Island last summer.

**Verb**

> visit

학생은 `last summer`라는 시간 표현을 단서로 **Simple Past**를 선택하여 다음과 같이 입력합니다.

```text
visited
```

정답 후에는 해당 문장에서 단순 과거형을 사용하는 이유에 대한 설명이 제공됩니다.

## 🌱 Educational Purpose

이 활동은 단순히 동사의 형태를 암기하는 것보다, 학생들이 **문맥 속 단서에 주목하여 시제를 판단하는 연습**을 하는 데 초점을 둡니다.

특히 다음 질문을 스스로 생각하도록 유도합니다.

- 이 행동은 **완전히 끝난 과거의 사건**인가?
- 구체적인 과거 시점이 제시되어 있는가?
- 과거의 행동이 **현재와 연결**되어 있는가?
- 지금까지의 경험을 말하고 있는가?

이를 통해 학습자가 Simple Past와 Present Perfect의 차이를 문법 규칙뿐 아니라 실제 문맥 속에서 이해하는 것을 목표로 합니다.
